This pre-lesson activity introduces a web-based Stack Data Structure simulator utilizing HTML, CSS, Bootstrap, JavaScript, and jQuery. The objective is to explore an un-wired starter template, understand the separation of concerns across different web technologies, and examine how a JavaScript Stack class manages LIFO (Last In, First Out) data operations before connecting interactive user controls during the class demonstration

Files
index.html - Contains the structure of the web page.
style.css - Defines the custom styles and appearance.
stack.js - Contains the Stack class and initial stack operations.
